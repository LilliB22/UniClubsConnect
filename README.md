# UniClubsConnect
University students often seek better ways to connect, share experiences, and collaborate within clubs. Existing platforms like Facebook Group or GroupMe are popular but not tailored to the needs of student organizations. This project will create an exclusive university social networking platform where club members can interact, share posts, organize events, and build stronger communities.
